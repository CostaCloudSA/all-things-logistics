## 🏛️ System Highlights & Architectural Pillars

1. **AI Engine**: **Gemini 3.7 Flash** for high-speed multi-agent reasoning, multimodal OCR, classification, and dynamic Golden Document generation.
2. **Security & Model Armor**: Local **Gemma** model on edge/device for PII/confidential commercial data scrubbing (+0.2 Bonus Points) + deterministic BigQuery tariff lookup gates.
3. **Deskless / Mobile-First Architecture**: Unified **BigQuery Enterprise Data Mesh** modeling every department (Telematics, Payroll, CRM, WMS, Customs) to eliminate expensive desktop workstations.
4. **Cross-Platform Client**: **Flutter** mobile-first Zero-Typing UX (Camera Vision OCR + Generative Voice-to-Trade + Smart Contextual Tap Chips + Adaptive Device Frame).
5. **Infrastructure as Code (IaC)**: **Terraform** managing Multi-Region Cloud Run, Cloud Pub/Sub, IAM Zero-Trust Service Accounts, and BigQuery Domain-Driven Data Mesh.
6. **Observability**: **OpenTelemetry** end-to-end reasoning chains and immutable compliance audit logs.
