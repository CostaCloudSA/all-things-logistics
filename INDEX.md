## 🏛️ System Highlights & Architectural Pillars

1. **AI Engine**: **Gemini 3.7 Flash** for high-speed multi-agent reasoning, classification, and dynamic Golden Document generation.
2. **Security & Model Armor**: Local **Gemma** model on edge/device for PII/confidential commercial data scrubbing (+0.2 Bonus Points) + deterministic BigQuery tariff lookup gates.
3. **Cross-Platform Client**: **Flutter** mobile-first Zero-Typing UX (Camera Vision OCR + Generative Voice-to-Trade + Smart Contextual Tap Chips), compiled to native Android/iOS APK and hosted Flutter Web for instant judge testing.
4. **Infrastructure as Code (IaC)**: **Terraform** managing Cloud Run, Cloud Pub/Sub, IAM Zero-Trust Service Accounts, and BigQuery Domain-Driven Data Mesh.
5. **Observability**: **OpenTelemetry** end-to-end reasoning chains and compliance audit logs.
